# Organization Policy Agent Instructions

Before changing this repository, read `CONTRIBUTING.md`, `GOVERNANCE.md`, `SECURITY.md`, `plans/README.md`, and every relevant plan.

- Treat community files and workflow templates as organization-wide public contracts.
- Create a plan before materially changing contribution, security, governance, or automation policy.
- Never include private infrastructure, provider pricing, credentials, customer data, or undisclosed vulnerability details.
- Explain rollout effects for every affected repository.
- Preserve clone-local instructions in product repositories; GitHub default community files are not a substitute for `AGENTS.md`.
- Record verification evidence before completing a policy plan.
