# Native AI Gateway

Native AI Gateway is an open-source, native-protocol multimodal AI API gateway.

It preserves official provider SDK and API formats while unifying authentication, routing, billing, failover, and managed media delivery across providers.

## Repositories

- [`gateway`](https://github.com/nativegatewayhq/gateway) — gateway data plane and official provider adapters
- [`conformance`](https://github.com/nativegatewayhq/conformance) — official SDK compatibility tests
- [`dashboard`](https://github.com/nativegatewayhq/dashboard) — user and operator console
- [`roadmap`](https://github.com/nativegatewayhq/roadmap) — cross-repository roadmap and architecture decisions

## Contributing

All repositories follow a Plan First workflow. Read each repository's `AGENTS.md`, `CONTRIBUTING.md`, and `plans/` directory before making a meaningful change.
